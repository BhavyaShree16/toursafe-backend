# 🔧 TourSafe Backend API

Backend service powering tourist registration, authentication, SOS alert management, and real-time communication for the TourSafe platform.

---

## Overview

The backend handles core business logic, tourist data management, authentication, emergency workflows, and real-time SOS alert broadcasting between hotels and police authorities.

---

## Features

- Tourist registration and management
- Hotel and police authentication
- Real-time SOS alert handling
- Emergency status tracking
- District-based tourist monitoring
- RESTful API architecture
- Socket.io-based real-time communication

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Socket.io
- JWT Authentication
- bcryptjs
